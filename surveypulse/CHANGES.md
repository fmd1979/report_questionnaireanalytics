## 0.1.0 beta — 2026100700

Primera actividad propia para Moodle 5.0: seis tipos de preguntas, matrícula activa, un envío por usuario, anonimato con participación separada e identificadores aleatorios, preguntas bloqueadas tras el primer envío, gráficos SVG, analítica por curso/categoría, Excel/CSV agregados, copias/restauración y API de privacidad.
